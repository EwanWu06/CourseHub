# Course Hub 设计文档

> 日期：2026-10-12 ｜ 状态：**待你审阅** ｜ 项目位置：`~/CourseHub`

## 一页看懂

- **是什么**：一个只在你 Mac 上运行的本地网页工具（`http://localhost:4123`），把所有学校的 Canvas 汇总到一处：所有作业与截止日期、课程全部内容、按周的中文学习讲解、每日日报、每周周报。
- **怎么连 Canvas（不用 access token）**：在工具弹出的 Chrome 窗口里登录一次（SSO / Duo 照常），工具保存登录状态，之后在后台定时只读同步。登录过期时先自动静默重登，不行再提醒你点一下。另外，工具会自动拿到每个学校的「日历订阅链接」，保证截止日期永远不漏。
- **AI**：用你的 Claude Max（5x）订阅调用 `claude -p`，生成学习讲解和日报里的安排建议。**截止日期只来自 Canvas 原始数据，AI 不碰日期。**
- **提醒**：每天 7:00 日报、周日 20:00 周报，通过 Mac 系统通知；未交作业在截止前 24 小时和 3 小时各提醒一次。

## 1. 目标与范围

### 1.1 成功标准

1. 打开一个页面，就能看到所有学校、所有课程的待办与截止日期（含是否已提交），按时间排好，不再漏交。
2. 每门课的 Canvas 内容（教学大纲、作业、模块、页面、文件、公告、讨论、成绩、收件箱）都能在这里浏览。
3. 学习页：每门课按周给出中文讲解，包括这周要学什么、要掌握什么、核心概念怎么理解，并附自测题；每个要点标明出自哪份 slide 的第几页。
4. 每天早上自动出日报（今天做什么），每周日出周报，用 Mac 通知提醒。
5. 登录一次后长期自动运行，不需要 access token。

### 1.2 v1 不做

- 不往 Canvas 写任何东西：不提交作业、不发帖、不标记已读。
- 不自动抓取 Canvas 以外的平台（Macmillan 的处理方式见第 8 节）。
- 手机不能直接访问网页，只在这台 Mac 上用；提醒只走 Mac 通知。
- 不做视频或录播转文字。

### 1.3 你说的 vs 我的假设

- **你说的**：
  - 你在多所学校上课，各用各的 Canvas，截止日期容易混；
  - 要有作业页，还要有学习页（按周讲解 slides）；
  - 要日报和周报，课程里的所有东西都要能看；
  - 大部分学校不能用 access token；学校稍后在网页里自己添加；
  - Canvas 以外还用 Macmillan Learning；
  - 推送只要 Mac 通知；先看设计文档再开工。
- **我的假设**（你可以改）：
  - 讲解用中文，术语保留英文；
  - 每周从周一开始；
  - 日报 7:00，周报周日 20:00；
  - 工具全程只读，数据只存在本机。

## 2. 方案选择

### 2.1 怎么连 Canvas

| 方案 | 做法 | 结论 |
|---|---|---|
| A. 独立浏览器登录 + 会话 | 工具打开一个独立的 Chrome 窗口让你登录，保存 cookie，之后用 cookie 调用 Canvas 网页自己在用的 `/api/v1` 接口 | **采用（主力）** |
| B. 日历订阅链接（.ics） | 每个 Canvas 账号自带一个私密订阅链接，不用登录也不会过期；但只有日期，没有内容和提交状态 | **采用（兜底）** |
| C. 读取你日常 Chrome 的 cookie | 不用单独登录，但需要钥匙串授权，而且依赖你的 Chrome 一直保持登录 | 暂不做 |
| D. 借用 Canvas 官方 App 的 OAuth 密钥拿 token | 违反服务条款，有封号风险 | 不做 |

### 2.2 产品形态

| 方案 | 结论 |
|---|---|
| 本地网页 + 后台常驻服务 | **采用**：有界面，能定时出日报；离线时也能看已经同步下来的内容 |
| 只做 Claude Code skill 或 MCP | 没有界面，也不能定时运行，所以只作为附加功能（见 11 节） |
| 浏览器扩展 | 浏览器关着就不能同步，也不能定时出报告，不采用 |

### 2.3 要不要基于现成项目

GitHub 上最接近的是 [xmike04/canvas-student-mcp](https://github.com/xmike04/canvas-student-mcp)（MIT 协议，用 cookie 读取 Canvas）。但它只支持一所学校，要手动复制 cookie，也没有界面、报告和学习讲解。

**结论：自己写**，只参考它处理接口的细节：去掉 `while(1);` 前缀、判断登录过期、提取 Office 文件里的文字。

## 3. 总体架构

```
┌──────────────────────── 你的 Mac ─────────────────────────┐
│ LaunchAgent（登录后自动启动，崩溃自动重启）                    │
│   └─ Course Hub 服务（Node 24 + TypeScript）                  │
│       ├─ 网页 + 数据接口      http://127.0.0.1:4123           │
│       ├─ 定时器：同步 / 日报 / 周报 / 提醒（错过的会补跑）       │
│       ├─ 同步引擎 ──cookie──▶ 各校 Canvas /api/v1（只读 GET） │
│       │            └─.ics──▶ 日历订阅链接（兜底）              │
│       ├─ 登录管理 ──▶ Google Chrome（只在登录时打开）          │
│       ├─ 资料处理：下载 PDF/PPTX/DOCX → 提取文字               │
│       ├─ AI ──▶ claude -p（你的 Max 订阅）                     │
│       ├─ 日报 / 周报 / Mac 通知                                │
│       └─ SQLite 数据库  ~/CourseHub/data/                      │
└────────────────────────────────────────────────────────────┘
```

**技术栈**

| 部分 | 用什么 |
|---|---|
| 服务端 | Node 24 + TypeScript，Node 直接运行 TS，服务端不用编译 |
| 数据库 | SQLite，用 Node 内置的 `node:sqlite`，不需要原生依赖 |
| HTTP 服务 | Hono |
| 浏览器 | playwright-core，只连接你已经装好的 Google Chrome，不额外下载浏览器 |
| 文件文字 | unpdf 提取 PDF 文字；ical.js 解析日历 |
| 网页 | React + Vite |

**目录**

```
~/CourseHub/
  src/     服务端：canvas/ auth/ sync/ content/ ai/ reports/ notify/ server/ cli.ts
  web/     网页（React）
  mock/    模拟 Canvas 服务器（测试用）
  test/    测试
  skill/   Claude Code skill
  data/    数据（不进 git）：db.sqlite、files/、text/、browser-profile/、auth/、logs/
```

**为什么不放桌面**：后台程序（launchd 启动的 node）读取「桌面」文件夹会被 macOS 权限拦截。

## 4. 登录与会话

### 4.1 第一次登录

1. 在设置页点「添加学校」，填名称和 Canvas 网址，再点「登录」。
2. 工具启动你的 Google Chrome 并打开 `https://<学校>/login`。这个 Chrome 用独立的配置目录 `data/browser-profile/`，不影响你平时用的 Chrome。
   - Chrome 用**普通模式**启动，工具只通过本机调试端口在旁边看页面状态。这样 Google、Microsoft 等登录页不会把它当成机器人拒绝。
3. 你正常登录（SSO、Duo 都可以）。建议勾上「保持登录」或「记住我」。
4. 工具检测到 `/api/v1/users/self` 返回成功后会：
   - 把该校 cookie 存到 `data/auth/<学校>.json`（文件权限 600）；
   - 读取你的个人资料，自动保存日历订阅链接；
   - 关闭 Chrome 窗口。

### 4.2 日常同步：不开浏览器

- 直接用保存的 cookie 发请求，只发 GET。
- 服务器返回新 cookie 时自动更新。
- 去掉返回内容开头的 `while(1);` 再解析。
- 请求头里的 User-Agent 和登录时用的 Chrome 保持一致。

### 4.3 过期与恢复

- **怎么判断过期**：请求被重定向到 `/login`、返回 401，或者返回的是网页而不是 JSON。
- **静默重登**：用同一个配置目录，在后台无界面地打开 Chrome，访问登录页，最多等 45 秒。如果学校登录页的「记住我」还有效，会自动跳回 Canvas，这时更新 cookie、继续同步。
- **静默重登失败**：学校状态改为「需要重新登录」，你会收到：
  - 一条 Mac 通知；
  - 网页顶部的红条，上面有「重新登录」按钮。

  这期间截止日期由日历订阅兜底，页面会标注「来自日历订阅，提交状态未知」。
- 同一时间最多只开一个 Chrome（你的内存是 8GB）。

### 4.4 允许 token 的学校

少数允许 token 的学校，可以在设置里直接粘贴 access token，用标准的 `Authorization` 请求头。

## 5. 同步

### 5.1 频率

- 白天（7:00 到 24:00）每 2 小时同步一次，夜里不同步，免得在 Canvas 访问记录里留下深夜活动。
- 服务启动时，或电脑唤醒时发现已经超时，立即补一次。
- 日报生成前（6:50）一定先同步一次。
- 设置页可以手动点「立即同步」。
- 各学校依次同步，每所学校同时最多 3 个请求；Canvas 返回的限流余量变少时自动放慢。

### 5.2 拉取什么（全部只读）

| 内容 | Canvas 接口 | 说明 |
|---|---|---|
| 个人资料、日历链接 | `users/self/profile` | |
| 当前课程 | `courses?enrollment_state=active`（含学期和成绩） | 只保留没结课的（课程或学期的结束日期为空，或不早于 7 天前）；可以在设置里隐藏 |
| 作业和我的提交状态 | `courses/:id/assignments?include[]=submission` | |
| 待办（Canvas 计划器） | `planner/items` | 补充测验、讨论、带待办日期的页面，以及提交状态 |
| 缺交 | `users/self/missing_submissions` | |
| 模块和条目 | `courses/:id/modules?include[]=items` | 条目太多时逐个模块拉取 |
| 页面 | `courses/:id/pages`，再取每页正文 | 更新时间变了才重新拉正文 |
| 文件 | `courses/:id/files` | 老师隐藏了「文件」页时，改从模块条目逐个获取 |
| 公告 | `announcements?context_codes[]=course_:id` | 从学期开始算起 |
| 讨论 | `courses/:id/discussion_topics` | |
| 测验 | `courses/:id/quizzes` | |
| 日历事件 | `calendar_events` | 考试、课堂活动等 |
| 教学大纲 | `courses/:id?include[]=syllabus_body` | |
| 收件箱 | `conversations` | 只读列表，打开时不标为已读 |

### 5.3 日历订阅兜底

- 每次同步都拉一次 .ics，这一步不需要登录。按 UID（例如 `event-assignment-<id>`）对应到具体作业。
- 合并规则：
  - 接口数据优先；
  - 接口不可用时，用订阅数据更新截止时间；
  - 订阅里有、接口还没同步到的作业，也会显示出来。

### 5.4 变化检测

每次同步都和上次结果对比，记录以下变化，用于日报的「动态」栏和即时提醒：

- 新作业；
- **截止时间变化（尤其是提前）**；
- 新公告、新文件；
- 成绩公布；
- 新增缺交。

## 6. 课程内容与文件

- **只下载文档类文件**：PDF、PPT/PPTX、DOC/DOCX、TXT/MD。
  - 单个文件上限 50MB，总缓存上限 3GB。
  - 超过上限时，先清理已结课课程的文件，再清理最久没看的。
  - 你的硬盘现在只剩约 11GB。剩余空间低于 2GB 时，暂停下载并提醒你。
- **文字提取**：
  - PDF 按页提取；PPTX 按幻灯片提取（包括讲者备注）；DOCX 提取正文。
  - 扫描版 PDF 没有文字层，会被标记出来，生成 AI 讲解时让 Claude 直接看页面图片。
- **浏览**：
  - PDF 在浏览器里直接打开，可以跳到指定页；
  - PPTX 和 DOCX 显示提取的文字，旁边有「用 PowerPoint/Word 打开」按钮（你的 Mac 装了 Office）。
- **Canvas 页面和公告里的图片、链接**：
  - 图片通过本地代理带着登录状态取回，所以能正常显示；
  - 指向 Canvas 内部的链接改成在本工具里跳转，其他链接在新标签页打开；
  - 外部工具（Zoom、Macmillan 等）显示为「在 Canvas 中打开」。

## 7. 按周组织与 AI 学习讲解

### 7.1 周次怎么算

- **第 1 周**：课程（或学期）开始日所在那周的周一。没有开始日期时，用最早的截止日期或模块解锁日期推断。
- **模块归到哪一周**，按下面顺序尝试：
  1. 看模块名里有没有周次，比如「Week 3」「Wk 3」「Weeks 3–4」「第 3 周」；
  2. 看模块的解锁日期；
  3. 看模块里各作业截止日期的中位数；
  4. 让 AI 读教学大纲里的进度表，把主题和章节对应到周（每门课只做一次，结果缓存）；
  5. 以上都不行，放进「未分周」。

### 7.2 每门课每周的讲解包含

1. 本周一句话概览。
2. 学习目标：学完这周，你应该能做到什么。
3. 核心概念讲解：每个概念讲「是什么、为什么、例子、容易错的地方」，公式用 LaTeX 渲染。
4. 必背速查：定义、公式、关键结论。
5. 和作业、考试的关系：本周要交哪些作业（截止时间由程序从数据库填入），可能会怎么考。
6. 5 到 8 道自测题，答案默认折叠。
7. 建议学习顺序和预计用时。
8. 资料出处：每个要点标明来自哪份文件第几页，点一下直接打开那一页。

**资料不足时**（比如这周只有一个视频链接），讲解会明确写「本周资料有限，以下为基于课程主题的通用讲解」，不会假装是老师讲的内容。

### 7.3 怎么调用 AI

- **调用方式**：`claude -p`，走你的 Max 订阅，用隔离模式：
  - 不加载你的插件、钩子和 MCP（实测每次额外开销约 0.6k token，默认模式是 5.5k）；
  - 只允许读取本周的资料目录；
  - 输出结构化 JSON，网页按结构渲染。
- **模型**：默认 Sonnet；设置里可以改成 Opus，讲得更深，但更耗额度。
- **输入**：本周模块清单、slide 提取出的文字（带页码）、Canvas 页面正文、相关作业说明、大纲里本周的主题。图表或公式页光靠文字看不懂时，Claude 可以直接读 PDF 原页。
- **省额度**：
  - 自动生成「本周 + 下周」（周日晚上预先生成下周）；其他周在网页上点「生成」。
  - 资料没变就不重复生成；资料更新后，标注「有新资料，可重新生成」。
- **失败处理**：
  - 同一时间只跑一个 AI 任务；
  - 失败自动重试，最多 3 次，间隔逐渐拉长；
  - 额度用完时，等额度恢复后再继续。
- **资料太长时**（超过约 150 页），先逐个文件提炼要点，再合并成本周讲解。

## 8. Macmillan Learning

- 如果老师在 Achieve 里勾选了「Sync to Canvas」，那些作业会作为 Canvas 作业（外部工具类型）出现，所以会自动进入截止日期列表。
  - 这类作业打上「Macmillan」标签，并提示「截止时间以 Achieve 为准」。原因是 Macmillan 那边改了截止时间，不一定会自动同步回 Canvas。
- 没同步到 Canvas 的：可以在网页里「手动添加任务」（标题、课程、截止时间、链接），同样会进日报、周报和提醒。
- Gradescope、Pearson、McGraw-Hill、zyBooks 等外部工具的作业，也用同样的方法识别并打标签。

## 9. 日报与周报

### 9.1 日报（每天 7:00）

- 7:00 时电脑如果在睡眠，唤醒后补发。每次都先同步，再生成。
- **程序直接算的部分**（100% 来自数据）：
  - 已逾期或缺交的作业；
  - 今天截止、未来 3 天截止、本周剩余的作业；
  - 新公告、新成绩、截止时间变化；
  - 需要重新登录的学校；
  - 本周学习重点（来自学习讲解）。
- **AI 写的部分**：「今天怎么安排」。按紧急程度和预计用时，排成上午、下午、晚上几个时间块，再加一两句提醒。AI 失败时日报照常发，只是少了这一段。
- **Mac 通知**：例如「今天 3 项截止 · 最急：MATH 7 HW5 今晚 11:59」。点通知直接打开日报页。

### 9.2 周报（每周日 20:00）

- **上周回顾**：按时完成、迟交、缺交各多少，成绩有什么变化。
- **下周日程**：每天有哪些截止项；考试预警（作业或日历事件标题里有 exam、midterm、final、quiz 等词）。
- **下周学习**：每门课的主题，来自学习讲解；还没生成讲解的，用模块名代替。
- **工作量分布和 AI 建议**：哪天最忙，哪些作业要提前做。

### 9.3 其他提醒（可以在设置里关掉）

- 没交的作业，在截止前 24 小时和 3 小时各提醒一次。
- 以下情况同步后立即提醒：截止时间被提前、48 小时内截止的新作业、新公告。
  - 每所学校第一次同步时不提醒，免得一下子刷屏。
- 学校登录过期时提醒。

### 9.4 存档

所有日报和周报都会保存，在「报告」页可以翻看历史。

## 10. 网页界面

- 中文界面，课程名保持原文；每所学校一个颜色。
- **安全设置**：
  - 只监听本机 127.0.0.1；
  - 拒绝非本机的 Host 头（防 DNS rebinding）；
  - 所有修改类请求都要带自定义请求头，防止恶意网页伪造请求。

| 页面 | 内容 |
|---|---|
| 今天 | 今日日报；逾期、今天截止、3 天内截止的任务清单，可以在本地勾「已完成」（不写回 Canvas）；最新公告；各校登录状态 |
| 截止日期 | 按天分组的列表和月历；按学校、课程、类型筛选；「手动添加任务」；没有截止日期的作业单独列出 |
| 课程 | 所有学校的课程卡片，显示下一项截止、当前成绩、新公告数。点进去是课程详情，分概览（大纲）、作业、模块、页面、文件、公告、讨论、成绩、学习几个标签，每项都有「在 Canvas 打开」 |
| 学习 | 选一门课，看周列表（本周高亮），点进去看讲解；有「生成」和「重新生成」按钮，以及资料清单 |
| 报告 | 日报、周报存档 |
| 设置 | 见下方 |

**设置页包括**：

- 学校：添加、登录、状态、日历链接、常用链接（比如学生门户）
- 课程：隐藏、改名、改颜色
- 时间：同步频率、日报和周报时间、提醒
- AI：模型、自动生成范围、用量记录
- 存储：缓存上限、清理
- 同步日志

## 11. 运行方式

- **后台常驻**：用 macOS 的 LaunchAgent，登录电脑后自动启动，崩溃后自动重启。日志在 `data/logs/`。
- **定时**：由服务内部调度，每分钟检查一次有没有「该跑没跑」的任务。电脑睡眠时错过的任务，唤醒后补跑一次。
- **Mac 通知**：用一个小的「Course Hub」助手 App 来发，点通知能直接打开对应网页。第一次会请求通知权限。如果这个做不出来，就退回普通的系统通知。
- **命令行**：`coursehub status | sync | login <学校> | report daily|weekly | guide <课程> <周> | doctor`
- **Claude Code skill「course-hub」**：在 Claude Code 里直接问「我这周有什么作业」「讲讲 MATH 7 第 5 周」，它会通过命令行读取本地数据来回答。

## 12. 数据与隐私

- 所有数据只存在本机的 `~/CourseHub/data/`。登录 cookie 文件权限是 600；`data/` 不进 git。
- 只有在生成 AI 讲解或建议时，相关课程资料的文字会发给 Claude（用你的订阅账号）。
- 对 Canvas 只发 GET 请求，频率低：白天每 2 小时一次，每所学校最多 3 个并发。页面正文和文件只在有变化时才重新拉取。

## 13. 出错时怎么办

| 情况 | 处理 |
|---|---|
| 某门课或某个接口失败 | 不影响其他课程；写进同步日志；连续失败 3 次在网页上标黄 |
| 登录过期 | 先静默重登；失败就通知你，同时用日历订阅兜底 |
| AI 失败或额度用完 | 重试，并等额度恢复；日报去掉 AI 段落照常发；讲解显示「生成失败，点此重试」 |
| 硬盘剩余空间低于 2GB | 暂停下载文件并提醒 |
| Mac 睡眠 | 唤醒后补跑错过的任务，每个只补一次 |

## 17. 风险与限制

- **登录有效期因校而异**，从几天到几周不等。没有「记住我」的学校，可能每隔一段时间要你点一次「重新登录」。这期间截止日期由订阅兜底，不会漏。
- **老师能看到访问记录**：Canvas 的访问报告和「最后活动时间」会把工具的自动读取也算进去。工具只在白天同步、只在内容变化时拉取，以减少这类记录。
- **个别学校可能关闭了日历订阅**，那样兜底就失效了。这种情况少见，发生时设置页会提示。
- **扫描版 slide 没有文字层**，AI 要直接看图，更耗额度，也更慢。
- **Mac 开着时才运行**，合盖睡眠期间不同步。
- **接口不是官方承诺的**：用 cookie 读取是 Canvas 网页自己用的方式，但官方文档没有保证。Canvas 升级后可能需要小修。
